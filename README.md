# Aryan Electromech Engineers

Responsive company website and client-friendly admin panel built with Laravel 13, Inertia, React, TypeScript, Tailwind CSS and MySQL.

## Run locally

See [`laravel-app/README.md`](laravel-app/README.md) for XAMPP/MySQL setup, migrations, first admin login and the development server commands.

The public site runs at http://127.0.0.1:8000. The admin login is at http://127.0.0.1:8000/admin/login.
